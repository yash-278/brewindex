# Sketch Manifest

## Design Direction

Dark, developer-first aesthetic inspired by Raycast: near-black background (`#0e0e0e`), muted surface layers (`#1a1a1a`), electric blue-violet primary accent (`#7c6aff`). Generous whitespace, clean typography, vibrant hover effects. Scanning and discovery are the primary user action — icons and names carry visual weight, description provides context. Reference points: Raycast, GitHub dark mode.

## Reference Points

- **Raycast** — near-black bg, vibrant accent highlights, generous whitespace, keyboard-first feel
- **GitHub dark** — information density, muted grays, subtle borders
