<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Railway cron trigger → POST /sync (Hono) | Internal Railway private network; cron.ts calls Hono over private network using BACKEND_INTERNAL_URL |
| POST /sync handler → Railway Postgres | Drizzle queries cross TCP/SSL boundary to Railway Postgres |
| POST /sync handler → VERCEL_REVALIDATE_URL | After sync, Hono calls back to Vercel over public HTTPS |
| POST /sync → external APIs (formulae.brew.sh, api.github.com) | Outbound fetch calls constrained by existing SSRF allowlist in src/lib/fetch-allowlist.ts |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-07 | Elevation of Privilege | POST /sync called without auth | mitigate | CRON_SECRET bearer guard is first operation in syncHandler; returns 401 before any DB or external fetch work; identical pattern to existing sync/route.ts |
| T-05-08 | Information Disclosure | revalidateTag imported outside Next.js | mitigate | revalidateTag is NOT imported in backend/; the HTTP webhook pattern is used instead; enforced by acceptance criteria grep check returning 0 |
| T-05-09 | Spoofing | BACKEND_INTERNAL_URL set to a malicious external URL | accept | BACKEND_INTERNAL_URL is set by the Railway operator (developer) in Railway dashboard env vars; it is not user-supplied input; risk is internal misconfiguration not external attack |
| T-05-10 | Denial of Service | Unbounded sync loop / concurrent sync runs | accept | Railway cron interval is 6h, much longer than max sync duration (~5-10 min); Railway skips concurrent cron runs naturally; no additional guard needed |
| T-05-11 | Information Disclosure | CRON_SECRET / DATABASE_URL / GITHUB_TOKEN in backend/ logs | mitigate | Env validation check on missing keys logs key names only (not values); no console.log of secret values anywhere in sync handler |
| T-05-SC | Tampering | No new npm packages installed in this plan | accept | No new packages; all imports (hono, @hono/node-server, pg, drizzle-orm) already in package.json; slopcheck approved in research phase |
</threat_model>
