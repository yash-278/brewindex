## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Railway PORT mismatch | Railway injects PORT=8080; domain generation UI must specify 8080 not 3000. Entering wrong port causes connection refused. | advisory | Always check Deploy Logs for actual port before generating domain |
| Railpack npm ci fails | Railpack's hardcoded npm ci step fails on macOS-generated lock files (missing Linux-only @emnapi deps). | advisory | Use Dockerfile to bypass Railpack entirely |
| railway.toml must be at repo root | railway.toml in backend/ is silently ignored; Railway looks for it at the service root directory. | advisory | Always place railway.toml at repo root |
