<objective>
Create the Vercel-side ISR cache invalidation webhook that the Railway sync service will call after each completed sync.

Purpose: revalidateTag() is a Next.js-only function — it cannot be called from a Railway Node.js process. The standard pattern (documented by Next.js) is to expose a lightweight Route Handler that calls revalidateTag() inside the Next.js process, then have the external service call that endpoint. This webhook bridges the Railway→Vercel invalidation gap with zero additional secrets (reuses existing CRON_SECRET).

Output: src/app/api/revalidate/route.ts — a GET handler protected by CRON_SECRET bearer auth that calls revalidateTag('casks', 'max') and returns JSON.
</objective>
