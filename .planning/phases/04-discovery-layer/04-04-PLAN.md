Update `.env.example` to document required AWS credentials:

Create `scripts/categorize-casks.ts`:
- Import: `db` from '@/db', `casks` from '@/db/schema', `eq, isNull, and, sql` from 'drizzle-orm', `BedrockRuntimeClient, InvokeModelCommand` from '@aws-sdk/client-bedrock-runtime', `revalidateTag` from 'next/cache'
- Const `BEDROCK_MODEL = 'anthropic.claude-3-5-haiku-20241022-v1:0'`
- **Step 1**: Query uncategorized casks: `db.select({ id, token, name, description }).from(casks).where(and(eq(casks.is_active, true), isNull(casks.category)))`
- **Step 2**: For each cask, construct prompt: "Categorize this macOS application into one of these categories: Developer Tools, Productivity, Design & Graphics, Media & Entertainment, Utilities, Communication, Business, Education, Games, Other. Return ONLY the category name.\n\nApp: {name}\nDescription: {description}"
- **Step 3**: Use Bedrock on-demand inference (NOT batch) for simplicity — batch requires S3 setup which adds complexity for a one-time job. Call `InvokeModelCommand` with model ID, body: `{ anthropic_version: "bedrock-2023-05-31", max_tokens: 50, messages: [{ role: "user", content: prompt }] }`
- **Step 4**: Parse response JSON, extract category from `response.content[0].text`
- **Step 5**: Batch update DB every 100 casks: `db.update(casks).set({ category: extractedCategory }).where(eq(casks.id, caskId))`
- **Step 6**: After all updates complete, call `revalidateTag('casks')` to invalidate ISR cache
- Add try/catch with detailed error logging, count successful/failed categorizations
- Script runs via `npx tsx scripts/categorize-casks.ts`

**Note per D-01:** Script first checks if Bedrock credentials exist; if missing, log error with instructions to set AWS_REGION, AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY. This is a checkpoint for human-required AWS setup.

**Cost estimate per D-02 and RESEARCH.md:** ~7,659 casks × ~500 tokens avg = ~3.8M tokens. On-demand pricing: $8/1M input tokens = ~$30 total (acceptable for one-time job; batch would save 50% but requires S3 bucket setup).
