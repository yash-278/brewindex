## Interaction Patterns

### Category Filter Pills
- **Default state:** "All Apps" pill active (accent border + dim background)
- **Inactive pills:** Surface background, border, muted text
- **Hover:** Surface hover background
- **Active:** Accent border (1px solid primary), accent dim background, primary-hover text
- **Transition:** `all 0.15s ease` (consistent with existing cards)

### Sort Dropdown
- **Type:** shadcn `Select` component or native `<select>` styled to match
- **Default:** "Popular" selected on page load
- **Style:** Surface background, border, matches filter pill height (~32px)
- **Dropdown panel:** Surface-raised background, border, shadow-md
- **Selected option:** Primary text color

### GitHub Stats Card (Detail Page)
- **Layout:** Horizontal stat row with separator dividers
- **Stats order:** Stars | Forks | Open Issues
- **Each stat:** Icon (lucide) + count + label
- **Focal point:** Star count (primary stat) — Emphasized with larger icon size (20px vs 16px for others) and primary color accent
- **Link:** "View on GitHub" button below stats (or integrated in heading)
- **Visibility:** Only rendered if `github_enriched = true` and `github_stars` exists

### Star Badge (Browse Cards)
- **Position:** After install count pill in metadata strip
- **Style:** Same pill pattern as install count (dim primary background, primary border, primary-hover text)
- **Icon:** "★" character (not lucide icon) for compactness
- **Visibility:** Only rendered if `github_enriched = true` and `github_stars` exists

### Loading States
- **Filter/sort changes:** Use existing skeleton pattern from `src/app/browse/loading.tsx`
- **Pagination:** Skeleton grid appears instantly while ISR loads new page (per D-14)

### URL State Persistence (per D-06)
- **Pattern:** `/browse?category={slug}&sort={key}&page={N}`
- **Example:** `/browse?category=developer-tools&sort=alphabetical&page=2`
- **Back button:** Full state restoration (category + sort + page + scroll position)

**Source:** 04-CONTEXT.md decisions D-05 through D-16, `.claude/skills/sketch-findings-brewindex/SKILL.md` § Interaction

| Mobile (< 640px) | 1 | 100% | 24px |

```
┌─────────────────────────────────────────────────┐
│  [All Apps] [Developer Tools] [Productivity] … │  ← Category pills (wrap on mobile)
```

**Mobile:** Stack filter pills (wrap) above sort dropdown (full width)
**Desktop:** Pills left-aligned, sort dropdown right-aligned, same row

```
│  [View on GitHub →]                             │  ← Link button (subtle style)
```

**Position:** Below install command section, above metadata grid on detail page
**Visibility:** Only if `github_enriched = true`

## Accessibility

- **Category filter pills:** ARIA role="group", aria-label="Category filter", aria-pressed state on active pill
- **Sort dropdown:** Semantic `<select>` or shadcn Select with proper labeling
- **GitHub stats card:** Semantic `<section>` with heading, stats as `<dl>` definition list
- **Star badge:** aria-label="GitHub stars: {count}" for screen readers
- **Keyboard navigation:** All filters/sort controls keyboard-accessible (tab, enter, arrow keys)
- **Focus states:** Visible focus ring (accent color) on all interactive elements

**Source:** Standard WCAG 2.1 AA requirements, consistent with existing component accessibility patterns
