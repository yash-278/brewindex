    Imports: Octokit from '@octokit/core', throttling from '@octokit/plugin-throttling'.

    Create throttled Octokit class: const ThrottledOctokit = Octokit.plugin(throttling). This is a module-level constant (not recreated per request).

    Export singleton: export const octokit = new ThrottledOctokit({ auth: process.env.GITHUB_TOKEN, throttle: { onRateLimit: (retryAfter, options, octokit, retryCount) => { if (retryCount < 2) return true; }, onSecondaryRateLimit: (_retryAfter, _options, _octokit) => { return true; } } }). The throttling plugin handles all primary and secondary rate limit retries automatically — do NOT add manual sleep loops or batch delays.

    Define constants:
    - GITHUB_REPO_PATTERN = /^https:\/\/github\.com\/([^\/]+)\/([^\/\?#]+)/
    - EXCLUDED_OWNERS = new Set(['googlefonts'])

    Export function extractGithubRepo(homepage: string): { owner: string; repo: string } | null.
    Implementation: match homepage against GITHUB_REPO_PATTERN. If no match, return null. Extract owner = match[1], repo = match[2]. If EXCLUDED_OWNERS.has(owner.toLowerCase()), return null. Return { owner, repo }. PITFALL 7: URLs like 'https://codeql.github.com/' or 'https://docs.github.com/en/...' do NOT match GITHUB_REPO_PATTERN because they lack /{owner}/{repo} path segments — regex correctly returns null for them.

    Export async function fetchGithubStats(owner: string, repo: string): Promise<{ stars: number; forks: number; issues: number } | null>.
    Implementation: call octokit.request('GET /repos/{owner}/{repo}', { owner, repo }) inside try/catch. On success: return { stars: data.stargazers_count, forks: data.forks_count, issues: data.open_issues_count }. On error: extract status from (err as { status?: number }).status. If status === 404 or 403: console.warn(`[github] ${owner}/${repo} inaccessible (${status})`), return null (per D-04: log failure, return null, caller sets github_enriched=false). Re-throw any other error.

    Note: D-02 was corrected by RESEARCH.md — only 1,083 casks have github.com homepages, not 7,659. The 1-hour sleep and 4,500-batch strategy from the original D-02 is NOT implemented. A single sequential pass of 1,083 requests with @octokit/plugin-throttling completes in ~3-5 minutes, well under the 800s function limit.

|----------|-------------|

| cask.homepage field → GitHub URL extraction | homepage values are from Homebrew API (Zod-validated in Plan 02); still need regex validation before use as owner/repo path segments |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Information Disclosure | GITHUB_TOKEN leakage | mitigate | Token used only in octokit constructor (process.env.GITHUB_TOKEN); never logged, never returned in API responses, never included in console.warn messages |
| T-04-02 | Elevation of Privilege | GitHub URL path traversal via homepage field | mitigate | extractGithubRepo() uses strict regex /^https:\/\/github\.com\/([^\/]+)\/([^\/\?#]+)/ — owner and repo segments exclude /, ?, # characters; no path traversal possible in octokit.request('GET /repos/{owner}/{repo}', ...) |
| T-04-03 | Denial of Service | 1,083 sequential GitHub API calls exceeding rate limit | mitigate | @octokit/plugin-throttling handles primary (5K/hr) and secondary (900/min) rate limits with automatic retry-after; no manual sleep needed |
| T-04-04 | Information Disclosure | GitHub 404/403 error details logged to console | accept | console.warn includes owner/repo path only (public Homebrew data); no secrets or internal state logged |
| T-04-05 | Spoofing | Non-GitHub URLs matching github.com substring query | mitigate | extractGithubRepo() regex must match full https://github.com/{owner}/{repo} pattern — a homepage like 'https://codeql.github.com/' does not match the regex and returns null |
  | T-04-SC | Tampering | npm/pip/cargo installs | mitigate | @octokit/rest 22.0.1 and @octokit/plugin-throttling 11.0.3 verified in Package Legitimacy Audit in RESEARCH.md; disposition=Approved |
