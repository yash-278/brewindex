<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| internet → cron route | External caller sends HTTP GET to /api/cron/sync with claimed Bearer token |
| cron route → Homebrew API | Server-side fetch to formulae.brew.sh — response content is untrusted |
| cron route → Neon Postgres | ORM writes to DB — all input is server-side-generated, not user-supplied |
| safeFetch → external favicon/icon services | Redirect chains from DuckDuckGo may land on attacker-controlled or private IPs |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Elevation of Privilege | GET /api/cron/sync | mitigate | CRON_SECRET Bearer comparison is FIRST statement in handler; return 401 immediately on mismatch; no work performed before auth check (SECU-03) |
| T-01-02 | Information Disclosure | Server-side HTTP fetches | mitigate | safeFetch() in src/lib/fetch-allowlist.ts blocks any hostname not in ['formulae.brew.sh', 'api.github.com', 'icons.duckduckgo.com', 'icon.horse']; redirect chains validated against private IP prefixes (SECU-04) |
| T-01-03 | Tampering | Homebrew API response injection | mitigate | Zod schema validation on all Homebrew API response shapes (HomebrewCaskSchema in Plan 02); reject malformed payloads with ZodError before DB write |
| T-01-04 | Information Disclosure | GITHUB_TOKEN in process.env | mitigate | Token accessed only via process.env.GITHUB_TOKEN; never logged; never included in API response bodies; stored as Vercel encrypted env var |
| T-01-05 | Denial of Service | Vercel Cron double-invocation | accept | Upsert-on-conflict makes duplicate cron invocations idempotent; two concurrent syncs write the same data safely; no lock needed for daily cadence |
| T-01-06 | Spoofing | CRON_SECRET timing attack | accept | Bearer comparison uses string equality, not constant-time compare. Risk is acceptable: attacker has no feedback channel (no timing side-channel via HTTP latency), secret is 32 hex bytes, and the endpoint is not on the public-facing API surface |
| T-01-SC | Tampering | npm package installs | mitigate | All packages verified in Package Legitimacy Audit (RESEARCH.md); all disposition=Approved; no [ASSUMED] or [SUS] packages |
</threat_model>
