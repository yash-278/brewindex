<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| cron route → formulae.brew.sh | 15.5 MB JSON response is untrusted external data |
| cron route → Neon Postgres | Batch inserts of mapped rows — all server-generated, no user input |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | Homebrew API response injection | mitigate | Zod HomebrewCaskSchema.parse() on bulk catalog response; AnalyticsResponseSchema.parse() on all three analytics responses; ZodError thrown on malformed payload before any DB write |
| T-02-02 | Denial of Service | 15.5 MB JSON parse blocking event loop | accept | Node.js JSON.parse handles 15.5 MB synchronously in <100ms; acceptable for a cron job that runs once/day and has 800s budget |
| T-02-03 | Tampering | SQL injection via cask field values | mitigate | Drizzle ORM parameterized inserts; no raw SQL string interpolation; onConflictDoUpdate uses sql template literals for column references only, not values |
| T-02-04 | Information Disclosure | Console logging cask data with secrets | accept | Cask data is public (from public Homebrew API); console.log in seed script logs counts and progress only, not raw cask content or env vars |
| T-02-SC | Tampering | npm/pip/cargo installs | mitigate | All new packages (zod, drizzle-orm) verified in Package Legitimacy Audit in RESEARCH.md; disposition=Approved for all |
</threat_model>
