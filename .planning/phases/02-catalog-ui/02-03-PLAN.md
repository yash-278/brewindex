<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL params→server | [token] path segment is user-controlled — used as DB lookup key |
| server→DB | getCaskByToken uses token as a query param |
| server→external | homepage URL from DB used in anchor href and getDomain parsing |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-08 | Information Disclosure | [token] param used in DB query | mitigate | Drizzle ORM parameterizes all queries — no raw string interpolation into SQL; notFound() is called for unknown tokens (no 500) |
| T-02-09 | Tampering | homepage URL from DB rendered in href | mitigate | getDomain helper wraps URL parsing in try/catch; `rel="noopener noreferrer"` + `target="_blank"` on all external links; no user-submitted URLs (only from Homebrew official JSON) |
| T-02-10 | Denial of Service | generateStaticParams queries top 500 at build time | accept | Read-only, bounded query (LIMIT 500); runs only at build time and is cached; no runtime attack surface |
| T-02-11 | Tampering | CopyButton writes to clipboard | accept | navigator.clipboard requires user gesture (click); no user-supplied data reaches clipboard — token comes from server-rendered props which originate from DB (Homebrew official source) |
| T-02-SC | Tampering | npm/npx installs | mitigate | No new npm installs in this plan — consumes packages from Wave 1 only |
</threat_model>
