Add three entries: `{ protocol: 'https', hostname: 'icons.duckduckgo.com' }`, `{ protocol: 'https', hostname: 'icon.horse' }`, `{ protocol: 'https', hostname: '*.public.blob.vercel-storage.com' }`. **src/lib/queries.ts:** Create new file. Import `unstable_cache` from `'next/cache'`, `db` from `'@/db'`, `casks` from `'@/db/schema'`, and `desc`, `eq`, `sql` from `'drizzle-orm'`. Export four `unstable_cache`-wrapped functions:

1. `getCasksPage(page: number)` — key `['casks-page']`, tags `['casks']`. Query: `db.select().from(casks).where(eq(casks.is_active, true)).orderBy(desc(casks.install_365d)).limit(48).offset((page - 1) * 48)`. Per D-05 (48/page) and D-06 (install_365d DESC).

2. `getCasksCount()` — key `['casks-count']`, tags `['casks']`. Query: `db.select({ count: sql<number>\`count(*)::int\` }).from(casks).where(eq(casks.is_active, true))`, return `result[0].count`.

3. `getCaskByToken(token: string)` — key `['cask-by-token']`, tags `['casks']`. Query: `db.select().from(casks).where(eq(casks.token, token)).limit(1)`, return `result[0] ?? null`.

4. `getTop500Tokens()` — key `['top-500-tokens']`, tags `['casks']`. Query: `db.select({ token: casks.token }).from(casks).where(eq(casks.is_active, true)).orderBy(desc(casks.install_365d)).limit(500)`.

All four MUST include `.where(eq(casks.is_active, true))` — never omit this filter (per 02-CONTEXT.md code insights). Cache tag must be exactly `'casks'` to match `revalidateTag("casks", "max")` in Phase 1 cron.

**src/lib/format.ts:** Create new file. Export one pure function `formatInstallCount(value: number | null | undefined): string` with these branches per UI-SPEC §Install Count Formatting: `value == null` → `'—'`; `value >= 1_000_000` → `\`${(value / 1_000_000).toFixed(1)}M\``; `value >= 1_000` → `\`${Math.floor(value / 1_000)}K\``; else `String(value)`.

**src/lib/hash.ts:** Create new file. Define module-level constant `INITIALS_PALETTE` as `readonly string[]` with exactly these 6 values in order (per UI-SPEC §Initials Color Palette): `'#2563eb'`, `'#7c3aed'`, `'#059669'`, `'#d97706'`, `'#dc2626'`, `'#0891b2'`. Export three functions:
- `djb2(str: string): number` — hash: `let hash = 5381; for each char: hash = ((hash << 5) + hash + charCode) | 0; return Math.abs(hash)`
- `getInitialsColor(token: string): string` — returns `INITIALS_PALETTE[djb2(token) % 6]`
- `getInitials(token: string): string` — splits token on `-`, filters empty, if single part take first 2 chars uppercase, else take first char of first two parts uppercase

**src/lib/blur-data-url.ts:** Create new file. Define: `const svgPlaceholder = '<svg xmlns="http://www.w3.org/2000/svg" width="8" height="8"><rect width="8" height="8" fill="#1a1a1a"/></svg>'`. Export: `export const DARK_BLUR_DATA_URL = \`data:image/svg+xml;base64,${Buffer.from(svgPlaceholder).toString('base64')}\``. Color #1a1a1a matches `--color-surface` from UI-SPEC. No imports needed — Buffer is available in Node.js.
