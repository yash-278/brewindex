<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client→server (browse page) | searchParams ?page=N is user-controlled input |
| server→DB | DB queries run server-side; results are rendered into HTML |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04 | Tampering | searchParams ?page=N | mitigate | Clamp with `Math.max(1, parseInt(pageParam ?? '1', 10) \|\| 1)` — parseInt rejects non-numeric, Math.max rejects negative, falsy fallback handles NaN |
| T-02-05 | Denial of Service | Large ?page values | mitigate | If `page > totalPages`, redirect to last page; no runaway DB offset |
| T-02-06 | Information Disclosure | Card renders icon_url from DB | accept | icon_url comes from Phase 1 sync (trusted source); rendered via next/image which validates against remotePatterns allowlist |
| T-02-07 | Tampering | CaskCard Link href /cask/{token} | accept | token comes from DB (trusted); Next.js Link does not allow javascript: URIs; no XSS vector |
| T-02-SC | Tampering | npm/npx installs | mitigate | No new npm installs in this plan — consumes packages installed in Wave 1 only |
</threat_model>
